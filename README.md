# AI for Cell Tracking

## Project Background

Time-lapse microscopy allows scientists to observe how cells move, divide,
and change over time. Manual tracking is labor-intensive, and the performance
of automated methods can vary substantially across imaging conditions and
biological samples.

This Data Science Clinic project will evaluate open-source cell-tracking
methods using annotated datasets from the Cell Tracking Challenge and apply
promising approaches to UChicago stem-cell time-lapse microscopy data.

## Project Goals

1. Reproduce representative published results on selected CTC datasets.
2. Evaluate the sensitivity of each method to important parameters.
3. Apply promising methods to UChicago 2D and 3D live-cell data.
4. Assess performance through benchmark metrics, visual review, and limited
   manual annotation where feasible.
5. Deliver reproducible workflows and practical recommendations.
